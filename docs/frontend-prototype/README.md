## 导航规则

- 首页固定使用顶部导航，不展示侧边栏。
- “工作区侧栏”是个人偏好，只能在“用户设置 → 外观与布局”中启用。
- 即使启用侧栏，也只影响案件、阅卷、分析和复核等内部工作页，不改变首页。
- 设置页左侧区域是设置分类目录，不是全站业务侧边栏。

## 品牌与视觉语言

- 标识：天平主体叠加“证据、规则、人工”三节点，表达可追溯的人机协同。
- 品牌短句：**证据有源 · 规则有版 · 审核有痕**。
- 核心原则：**机器给出依据，人保留裁量**。
- 主方案“极光衡链”：深紫墨 `#281B43`、极光紫 `#7554F6`、证据青 `#20BFAE`、复核金 `#E6A126`、风险珊瑚 `#EE5879`。
- 备选方案：“朱砂曜金”和“深海青”均收在设置页色板中，方便评审时直接比较。
- 状态不只依赖颜色，还配合文字、图标和标签，避免误读。

## 参考转化

- 法律 AI 产品常见的深色权威底色与紫色任务强调，被转化为深紫墨底与极光紫，而不是沿用旧版素蓝灰。
- 法律工作台的“文件列表—原文—审阅/编码面板”结构，被转化为阅卷三栏图纸。
- 案件中心、共享材料库、来源引用和可见审核步骤，被转化为首页案件概览、依据卡片和人工复核链路。
