# 演示输入说明

本目录中的文件是用于评审操作和自动化测试的演示输入，明确不是智能体代码、提示词或知识规则。它们只在评审机本地加载到 `/data`，不会被构建成法律结论。

- `three_case_demo/`：三案结构化演示数据和字段约束，用于验证案件导入与来源映射。
- `boundary-case/generic-smoke-input.docx`：最小 DOCX 解析边界输入，用于检查上传、解析失败/缺失信息和人工阻断路径。
本包不附带宣称可直接形成司法结论的“成功案例”。三案数据用于验证结构、导入、来源映射和人工门闩；如果模型 Key、材料或知识覆盖不足，网页必须显示配置/覆盖不足，而不是生成伪成功结果。
