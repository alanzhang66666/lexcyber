# V1.2.1 功能收口与部署验收

## 交付内容
- F2 `RiskSignal` → F4 `RiskTransfer`：仅合成演示数据；冻结规则、Artifact、FactsVersion 与条件 trace。
- 同一 Artifact/Signal/目标 F4 重放幂等；旧 F2 事实版本确认后，原移交显示 `sourceStatus=stale`，不能由失效结果发起新移交。
- F4 事实确认时冻结 `proofs`（候选事实 ID + 证据 ID）；审查路径仅读冻结快照，不读取实时候选列表。
- 当前 Artifact 复核决定不可覆盖，同一决定完全重放不会写第二条；归档同一 Artifact 幂等。
- 写操作要求环境变量 `DEMO_WRITE_TOKEN`，未配置则拒绝写操作；访问公开的合成数据只读接口仍无需登录，故**禁止真实数据**。
- F1/F2/F3 原有演示继续保留，F4 仅为证据核对提示，不含自动罪名和刑期。

## 单容器运行
```sh
cd 人工智能大赛校赛版
npm install
npm test
DEMO_WRITE_TOKEN=change-this-to-a-long-random-secret PORT=8080 npm start
```
JoyCode 设置运行时 Node.js、启动 `npm start`、唯一监听端口 8080，配置 `DEMO_WRITE_TOKEN`、`DATABASE_URL`（JoyCode MySQL 地址）为 Secrets。页面通过「设置写入令牌」填写同一值，令牌仅保存在浏览器会话中。若没有 MySQL，服务仅提供重启即重置的内存模式；不得将它称为持久化交付。

## 验收步骤
1. F1 确认 → 运行 → 复核；F2 确认 → 运行 → 风控线索。
2. F2「证据与法律路径」选择一个线索移交 F4；重复提交不重复创建。
3. F4「证据与法律路径」查看移交来源；手工新增合成证据 → 候选事实 → 核验 → 冻结 FactsVersion → 运行审查路径。
4. F2 修改事实并再次确认；F4 显示来源已失效，原移交历史仍存在。
5. 复核/归档重放检查，未配置令牌访问写入接口须返回 401。
6. MySQL 开启后重启服务，复查移交、事实版本和归档是否持久化。

## 自动化测试
`npm test` 会运行原有工作流和法律审查测试、新增 `tests/closeout.test.js`。本文件不声称已经通过 JoyCode 或 MySQL 实际运行；部署前必须保存真实测试日志与环境验收证据。

## 限制
校赛版沿用简化 JSON 状态表，不含正式 RBAC、多用户数据隔离、真实卷宗解析、正式法律规则/会签、在线模型自主判断、真实审计不可抵赖性；原主系统未修改。
