# 总需求与优先级

## 基线与边界

- 当前现役栈：Java/Spring（server）、Python Engine（engine）、Vue（web）、PostgreSQL。事实快照、注册表会签、任务/工件版本、复核和归档沿用既有管道。
- 不修改冻结比赛包、历史已批准规则/模板、历史会签记录、已应用 Flyway 迁移。
- 计算结果均为**辅助研判**；`human_review_required=true`；无证据、冲突和法源缺口不能推断司法终局结果。
- 业务状态单独区分 `met / not_met / unknown / conflicted`；执行状态 `calculated / blocked / not_applicable` 不可混作法律结论。

## 分批交付

| 优先级 | 工作 | 完成标准 |
|---|---|---|
| P0 | 旧新法源、金额口径、规则补充、候选路径声明 | 新版本可播种；无未会签依赖；证据闭包完整 |
| P1 | 四份文书模板、条件分支与程序审查字段 | 互斥与条件必填均由服务端校验，缺失阻断 |
| P2 | 页面与双时点措辞整改 | 不再出现无上下文“刑期 N 个月”及定罪/合规终局结论 |
| P3 | V27迁移验收、播种、法学签署、旧版退役、测试 | 记录内容哈希、签署人、时效、工件版本；/v1 保持501 |

## 特别提醒

- 提供资金5万宜有 `provided_funds_amount` 专门金额类型（本包按两类新金额写要求）。
- 八条严重情节是本轮确定性路径，不是法定情形全集；严重后果与其他情节另建人工核查。
- `presumed` 不可直接算明知成立，但现实证据推认“实际知道”的证明过程仍需保留。
- 单纯“上游既遂”既不能排除帮信，也不能确立掩隐；需结合介入时间、持续帮助和事前通谋。
- 案例A规则维持9.0个月，坦白后8.1个月；原案载12–18个月只修改非冻结演示说明。
