# 最终验收与发布清单

## 法源

- [ ] 2016独立版本有原文链接、条号、文号、效力起止、版本和哈希。
- [ ] 2025修正版有生效日期及新条号；历史行为不会被直接匹配新法。
- [ ] 跨版、缺失时点、缺失签署时有效结果正确阻断。

## 规则与事实

- [ ] 构成要件仅最终接受 actual knowledge，不将presumed作为终态。
- [ ] 帮助行为三类归并，技术支持四个子类可追溯。
- [ ] 八条择一且S1无30万条件、S6/S7账户总流入为独立kind。
- [ ] 增加严重后果/其他严重情节人工核查。
- [ ] 帮信/掩隐/诈骗candidate_paths有actor、正反证据、独立法源、排除理由；未确认不排除。
- [ ] 实名制度与实际执行区分；日志六个月门槛保持。

## 文书与页面

- [ ] 四份模板真实存在且各自有法学审定格式与字段约束。
- [ ] 起诉书身份、诉讼权利、补充侦查/延审、证据分类、附件、署名均有相应程序与正文处理。
- [ ] 不起诉类型互斥；附条件仅符合法定条件的未成年人；权利告知按类型生成。
- [ ] 主刑必填与免刑互斥；计算参考不能直接复制为正式建议。
- [ ] “刑期 N 个月”变辅助分析文案；四模块无自动裁判/定罪/违法用语。
