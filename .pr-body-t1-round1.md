## Summary
- Added owner-scoped `/v1/cases` and `/v1/documents` APIs matching the frozen T1 samples (`title`, `jurisdiction`, `asOfDate`, `metadata`; document `role` = `input` | `annotation`).
- Upload always stores bytes in MinIO, then in one transaction inserts the document, creates a parse task (`metadata.taskType=document.parse`), and writes the outbox. T2/T3 only poll `parseTaskId`.
- Bearer is required on cases/documents; case-scoped task get/result/retry are owner-only (401 / 404). Stub tasks without a case stay public so existing CI still works.
- Engine dispatches `document.parse` by metadata (not query text), re-reads stored bytes, wraps PDF/DOCX skill output as `document.parse.v1` with locators, and maps fatal/timeout to `DOCUMENT_PARSE_FAILED` / `DOCUMENT_PARSE_TIMEOUT`. Default `WORKFLOW_PROFILE` remains stub.
