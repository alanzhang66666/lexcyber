# Import staging durability and relational integrity fixes

This pass rechecks the previously raised high-risk behaviors in V11 and the Java import persistence path. Reservation now commits before MinIO I/O, composite foreign keys enforce account-scoped relationships, mapping target drift is rejected, and map-backed JSONB has matching object-shape/null handling. No blocker or high-severity behavioral issue remains in the four requested areas. **Watch for:** **[low, confirmed]** import-specific regression coverage is still absent.

**Verdict**: APPROVED

## High-level view

Raw package creation uses two explicit database transactions around MinIO. The reservation commits before `put`; later storage or status-transition failures leave an addressable `failed` or `uploading` row.

V11 links batches/items through `(owner_account_id, batch_id)`, mappings to their exact batch/item, cases through `(owner_account_id, case_id)`, and documents through `(case_id, document_id)`.

External identity updates proceed only when internal type/id, case, and nullable document targets match. Target drift affects zero rows and becomes HTTP 409 `IMPORT_MAPPING_CONFLICT`.

Map-backed JSONB columns reject non-object shapes. Nullable columns retain SQL NULL semantics, while Java map copies preserve null-valued JSON members.

## Reservation-first upload keeps failures recoverable

The first `TransactionTemplate.executeWithoutResult` contains only `insertBatchReservation`, so commit completes before `rawPackages.put`. A reservation commit failure exits before MinIO receives an object. A `put` failure attempts deletion and independently marks the committed row `failed`; failure of either compensation action still leaves the durable row. If MinIO succeeds but the uploaded-state/audit transaction fails at statement or commit time, rollback leaves the original `uploading` row and storage key for reconciliation.

## Composite keys close the ownership graph

V11 adds candidate keys on `cases(owner_account_id, id)` and `documents(case_id, id)`, plus the required batch/item candidate keys. An item cannot name another owner's batch or case. A mapping must reference an owner-matching batch, an item in that batch, an owner-matching case, and—when present—a document in that case.

## Conditional upsert turns target drift into 409

`upsertMapping` gates `DO UPDATE` on equality of internal type/id, case id, and null-safe document id. PostgreSQL reports zero changed rows for a drifted target; the follow-up external-identity lookup identifies the collision and raises HTTP 409 instead of rebinding the target.

## JSONB shape matches the Java map contract

V11 applies `jsonb_typeof(...)= 'object'` to metadata, diff, error, input, and output columns, with SQL NULL allowed only where nullable. `ImportJson.copyMap` uses an unmodifiable `LinkedHashMap`, preserving null-valued entries for Jackson serialization/deserialization instead of rejecting them as `Map.copyOf` did.
